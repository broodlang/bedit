# UX/UI review, round 3 (2026-11-17): no GPU, the terminal, structure, first hour

Four read-only tracks on bedit 0.10.0 / brood 0.54.0: the CPU (no graphics card) window path,
the terminal (`-nw`) path, the view layer's coupling, and a wide first-hour UX pass. Rounds 1-2
(latency, pacing, hinting, span trees) are in `ui-feel-research-2026-11-16.md`.

## Measured

- CPU full-screen text redraw, 1080p (headless `gui/capture`, ~4.5 ms of it capture overhead):
  gray 19.3 ms, subpixel 38.8 ms; 4K at 1x 79 / 180 ms. The cost was a `powf` per rim pixel
  (three for subpixel): `TextInk` was built per glyph, so its ground cache never lived past one.
  **After the blend tables: gray 9.2 ms, subpixel 11.6 ms** (3x / 5x on the raster itself).
- Terminal, 120x40 pty: C-n 640-740 bytes, 7-11 ms; one wheel notch ~7 KB (the whole screen);
  C-v 6.8-8.6 KB, 58% of it SGR (every colour change restated from a reset, ~35 bytes);
  1,250 syscalls/s idle (a 20 ms wake that reopens /dev/tty twice); 2.0 + 0.5 s at startup when
  the terminal answers no kitty-keyboard or graphics query.

## Part 1 — what Brood gains

CPU window (`crates/lisp/src/host/gui/backend`):
1. Blend tables per (colour, ground, lift), filled lazily by coverage — DONE (ink.rs).
2. A scroll copies strips in place (`copy_strips`), scratch kept for opposite-way moves — DONE.
3. Resize: keep the old canvas (rows anchor top-left), draw only what is new; don't paint the
   stale frame at the new size and then the laid-out one (35-80 ms per configure today).
4. A zoomed pane (cell region) diffs as cells, not one opaque op: typing in it redraws the pane.
5. A copy over a column span, so one pane of a side-by-side split scrolls by copying.
6. Composite disjoint row bands on threads (`std::thread::scope`), glyphs built first.
7. Per-frame bookkeeping: keep the old op list, FxHash glyph keys, reject a text op by columns.
8. Later (L): our own wl_shm backend, three buffers, draw in place, shm-offset scroll.
9. `TextAa::Auto` follows the desktop (gray on GNOME): subpixel is 2.3x gray on CPU.

Terminal (`crates/lisp/src/builtins/terminal`):
10. SGR deltas (only what changed), `CSI K` / `CSI n X` for blank runs — ~35-40% fewer bytes.
11. The first frame and a resize clear to the theme's background, not the terminal's.
12. Idle: size asked only when SIGWINCH moved, the tty kept open, block in poll — no 20 ms wake.
13. A lone ESC waits ~20 ms for its key when the kitty protocol is off (split ssh packets).
14. Mouse: click counts (double/triple click), horizontal wheel, 1002 not 1003 (or deliver
    motion for hover).
15. Scrolling by scroll region (`DECSTBM` + `SU/SD`) where row bands moved; diff the rest.
16. Startup queries in one batch ending in DA1 (kitty keys, graphics, OSC 10/11, DECRQM
    2026/2027, XTVERSION); the decoder reads OSC/DCS replies. Truecolor and undercurl from the
    replies, not `COLORTERM` (ssh).
17. OSC 10/11/12: the terminal's own colours and the cursor's follow the theme; reset on leave.
18. `:title` / `:cwd` display entries (OSC 0/2, OSC 7); dim / strike-through; wide-grapheme guard.

Shared std (from the structure track; each has a caller besides bedit):
19. `editor/display/chunk-ops`: tab- and width-aware chunks → text ops (observer and
    brood-terminal clip by `count`, wrong for wide glyphs).
20. Layered face lookup in `editor/highlight` over span trees (the REPL line editor).

## Part 2 — what bedit does

First-hour UX (from the wide pass; screenshots under the session scratchpad `ux/`):
- `*Messages*` read-only; `q` is one `quit-window` everywhere (back to the previous buffer, or
  close the split it opened).
- `C-x v v` back to VC (vim mode on a setting, `:keys-profile`), not a mode switch.
- Say once per language when its server is not installed; `lsp-servers` lists missing ones.
- M-x: the real total, word-start/prefix ranking, a starter set before history.
- Completion hides `%`-names; find-file hides lock/autosave files and `.git`, dotfiles last.
- Developer telemetry ("slow view 83ms …") out of `*Messages*`.
- `--help`; `C-z` is not "minimise" in the window; the startup log line not left in the shell.
- -nw: ESC is a Meta prefix; floating cards get a box-drawing border.
- A start page (recent files/projects, keys) instead of the editable scratch; settings easy to
  find (`open-settings`, Emacs aliases, live theme preview that can be saved).
- Mode line: drop the `:status` repeat, a clear active-pane cue; which-key groups; transient
  keys first; truncation marker; line numbers off in prose/special buffers.

Structure (high cohesion, low coupling; each step keeps a golden-frame test green):
0. A golden-frame test of ~10 scenarios. 1. Dead `call-if-bound` shims removed — DONE.
2-3. std chunk-ops and layered face lookup. 4. One layout owner. 5. A `pane-view` record.
6. A `row` record instead of the 12-slot vector. 7. An always-present row table (no nil path).
8. A face-layer registry with `:blend` (region, isearch current match, link hover, bracket,
   diagnostic underline move out of spanpaint/view). 9. End-of-line note sources.
10. A gutter-mark registry; the gutter cache in `gutter`. 11. Row-extra registry; settings
   out of `scroll`. 12. `panecompose` with memo deps from the registries. 13. Echo sources.
14. Public readers for spell / rainbow / headerline instead of private keys.

Tool fix found on the way: `tools/screenshot.blsp` loaded only what `main` reaches, so every
mode registered by a module nothing names (Ruby's, in lang-scripts) was missing — files showed
`(text)`. It now loads every source module first, as the bundle does.
